# SecureX Frontend — Cryptographic Web Interface

React + TypeScript + Vite + Tailwind CSS portal for client-side zero-trust file encryption and ephemeral link exchange.

## Features
- **Client-side Cryptography**: Web Crypto API AES-256-GCM encryption/decryption.
- **SHA-256 Checksum**: Calculates and verifies binary integrity before save.
- **Ephemeral Links**: Recipient portal with automatic expiration and download counter evaluation.
- **Admin Dashboard**: System security audit logs and user management.

## Running Locally
```bash
npm install
npm run dev
```
Open `http://localhost:5173`.
